# Opus AuditBundle

Audit logging for Symfony applications.

## Installation

```bash
composer require opus/audit-bundle
```

When using Symfony Flex the bundle is registered automatically. Otherwise add it
to `config/bundles.php`:

```php
return [
    // ...
    Opus\AuditBundle\OpusAuditBundle::class => ['all' => true],
];
```
